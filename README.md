## Key Definitions

### Flying Drones Sector
- **CPC B64U** — Unmanned aerial vehicles (main code since 2023)
- **CPC B64C39/024** — Aircraft of remote-controlled vehicle type (pre-2023)
- **CPC B64C2201** — Former UAV indexing scheme (legacy, kept for completeness)
- **Keywords** (optional): "unmanned aerial vehicle", "aerial drone", "quadcopter", etc.

See `CPC_CODES_REFERENCE.md` for full definitions, military use codes, and data quality notes.

### Military / Dual-Use / Civil Split (Q4)
- **Military**: B64U2101/15–19 (warfare codes) or F41, F42B (weapons)
- **Dual-Use**: B64U2101/31 (surveillance; excludes military)
- **Civil**: All remaining drones

### Benchmarks (for Comparison)
- **Manned aircraft**: B64C, B64D (excluding drones)
- **Autonomous road vehicles**: B60W60

## Important Notes

### Shared Sector Definition
The sector definition (CPC codes, keywords) is **shared by all questions**: change it in one place (configuration section at the top of each notebook) to keep results consistent.

### Truncation (Incomplete Years)
The last ~3 priority years are incomplete in PATSTAT (documents still in pipeline, not yet fully reclassified). They are:
- Shaded grey in all figures
- Excluded from growth analysis
- Not included in summary statistics

### Step 0 Precision Check
Before trusting any results, review the **precision samples** in Section 2.1b:
- Do CPC codes actually catch flying drones?
- Do keywords bring in false positives?
- Adjust codes/keywords if needed and re-run

### Applicant Names
Company names in PATSTAT may vary (e.g., "Leonardo", "Leonardo SPA", "Finmeccanica"). The notebooks use wildcard patterns to match variations, but **precision is approximate**. See `CPC_CODES_REFERENCE.md` for the patterns used.

## Technical Details

| Aspect | Detail |
|---|---|
| **Database** | PATSTAT (EPO), accessed via TIP |
| **Time window** | 2000–2025 (user-configurable) |
| **Family level** | Earliest priority year (the date the invention was first filed anywhere) |
| **Counting** | Fractional: each family/application is split equally across applicants, inventors, and CPC classes (shares sum to 100%) |
| **Offices** | IP5 (EP, US, CN, JP, KR) and international PCT applications |
| **Export** | CSV tables (for deck) and PNG figures (embedded in slides) |
